The <Badge color="yellow">RefillRx</Badge> endpoint is intended to create refill for already submitted and transmitted prescriptions.

---

## Rx Identifiers

There are three types of Rx identifiers that may be used to trigger the 'Refill Rx' request. The request must specify the correct qualifier based on the Rx identifier being used:


`SSPrescriberOrderNumber`
* Provided value must correspond to the Surescripts Prescriber Order Number generated by Surescripts at the time of initial Rx transmission


`RxNumber` 
* Provided value must correspond either to:
   * The Rx identification number which was returned during Rx creation process.
   * The patient-facing Rx number that was generated by the pharmacy's software system upon successful transmission of the Rx <br/>
     
---

## Body (application/json)

### Required Fields

| Field | Type | Requirement | Description |
|------|------|----------|------------|
| rxNumber | string | <Badge color="orange" size="sm" shape="rounded">Conditional</Badge> | The Rx identification number which was returned during Rx creation process.<br/><br/>**Required to provide at least one:**<br/>• `rxNumber`<br/>•`SSPrescriberOrderNumber` (if using SureScripts) |
| SSPrescriberOrderNumber | string | <Badge color="orange" size="sm" shape="rounded">Conditional</Badge> | Surescripts prescriber order number information.<br/><br/>**Required to provide at least one:**<br/>• `rxNumber`<br/>•`SSPrescriberOrderNumber` (if using SureScripts) . |
| clinicNumber | integer | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Clinic Number information provided by Wells |
| shippingAddress | object | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Shipping address information |

#### shippingAddress (object)

| Field | Type | Requirement | Description |
|------|------|----------|------------|
| shippingName | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Recipient name |
| shippingAddress1 | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Address line 1 |
| shippingAddress2 | string | <Badge color="surface" size="sm" shape="rounded">Optional</Badge> | Address line 2 |
| shippingAddress3 | string | <Badge color="surface" size="sm" shape="rounded">Optional</Badge> | Address line 3 |
| shippingCity | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | City |
| shippingState | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Two-letter state code |
| shippingZip | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | ZIP code |


### Optional Fields

| Field | Type | Requirement | Description |
|------|------|----------|------------|
| notesToPharmacy | string | <Badge color="surface" size="sm" shape="rounded">Optional</Badge> | Additional notes to be sent to pharmacy associated with refill process. |
| shippingMethod | string | <Badge color="surface" size="sm" shape="rounded">Optional</Badge> | Shipping method information. List of preferred values will be provided upon request. |


## Response

| Field | Type | Description |
|------|------|------------|
| status | string | “Ok” if RX refilled successfully |
