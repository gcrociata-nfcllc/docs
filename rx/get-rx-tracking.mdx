<Card title="Endpoint" icon="text-align-start" horizontal href="/">
  GET `<path to API root>/api/Rx/GetRxTracking`
</Card>

The <Badge color="yellow">GetRxTracking</Badge> endpoint returns tracking information for an RX order.

---

## Query Parameters

| Field | Type | Required | Description |
|------|----------|------|------------|
| rxNumber | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | The Rx identification number which was returned during Rx creation process. |

## Response

| Field | Type | Description |
|------|------|------------|
| trackingCode | string | Tracking code information provided by the carrier. |
| carrierCode | string | The carrier code information used for the order. A list of supported carrier codes is provided below. |
| shippedDate | string | The timestamp indicating when the order was marked as ready to ship. |


### carrierCode (Supported Values)

- `LOC` — Local  
- `FEXP` — FedEx  
- `PICK` — Pickup  
- `UPS` — UPS  

<RequestExample>

```bash
GET /api/Rx/GetRxTracking?rxNumber=Rx_1234
```
</RequestExample>

<ResponseExample>

```json
{
  "carrierCode": "UPS",
  "trackingCode": "1Z872123412341",
  "shippedDate": "2025-03-04T14:15:16.704Z"
}
```
</ResponseExample>
