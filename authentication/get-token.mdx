---

The <Badge color="yellow">Get Token</Badge> endpoint serves as the primary entry point to the API, facilitating the generation of JWT (JSON Web Token) authentication tokens for client applications. 

Each client is provided with a unique `key` during setup, which is then sent to the <Badge color="yellow">Get Token</Badge> endpoint to generate the JWT token. This token must be included as a header key in subsequent API requests to authenticate and access protected endpoints.

<Note> When including the JWT token in subsequent API requests for authentication, it should be sent in the Authorization header using the Bearer scheme.</Note>

---

## Query Parameters

| Name | Type | Requirement | Description |
|----|----|----|----|
| key | string | <Badge color="red" size="sm" shape="rounded">Required</Badge> | Unique key provided by the pharmacy to each customer |


## Response

```json
"token"
```
